This is my *vault*

I make a note of things relative to what I'm learning anything really. Mostly system admin stuff, but also any kind of topic I'm currently interested in.

My point here is plainly to share my learning notes publicly so that others might find value and bring up discussions.

**Consider everything as work in progress**
## How is it structured ?

I'm trying to make this simple logic is as follow for now it looks as the following

| directory    | comment                                                                                                                                                                                              |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Inbox        | draft notes still ongoing process. This is where notes starts their lives before ending up in the *Zettelkasten*                                                                                     |
| Journal      | daily notes, everything that could be going in my mind. It's also a great way to link any new notes to at least something                                                                            |
| MOC          | Map Of Content. Really a place to hold an index of topic area. It helps to be a central place to start from. For example, there is a MOC for *Ansible* that links to some starting notes of ansible. |
| Zettelkasten | I'm using a Zettelkasten still method. Basically my notes are atomic and once I believe a note is *good enough*, I dump it from *Inbox* to *Zettelkasten*                                            |
| template     | a place where I hold my template notes for Obsidian                                                                                                                                                  |

I'm thinking of adding other directories for books reviews for example, but we'll see…

## What are you using ?

I try to make my notes rather atomic and keep the structure of the vault rather simple.
All of this is created through [Obsidian](https://obsidian.md/) .

To create the webpage you see, I'm using [Quartz](https://quartz.jzhao.xyz/) which helps render an entire vault into a static webpage that can be hosted anywhere; though everything is provided to be hosted on a github page.
